UPLOAD LÊN GITHUB PAGES:
1. Giải nén ZIP trên điện thoại hoặc máy tính.
2. Mở repository GitHub của bạn.
3. Chọn Add file > Upload files.
4. Chọn tất cả 9 tệp nằm trực tiếp trong thư mục giải nén (không upload thư mục cha).
5. Bấm Commit changes.
6. Vào Settings > Pages.
7. Chọn Deploy from a branch, branch main, thư mục /(root), rồi Save.
