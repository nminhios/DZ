CÁC TỆP ĐƯỢC ĐẶT CÙNG MỘT CẤP:
- index.html       Trang bio chính
- style.css        Giao diện và hiệu ứng
- script.js        Hiệu ứng, tương tác, chia sẻ và điều khiển nhạc
- config.js        Avatar và các liên kết
- cover.webp       Ảnh nền động
- cover-poster.jpg Ảnh nền tĩnh dự phòng
- favicon.svg      Icon trình duyệt
- robots.txt       Quy tắc crawler
- README.txt       Hướng dẫn này

CÁCH ĐƯA LÊN GITHUB PAGES:
1. Giải nén ZIP.
2. Mở repository GitHub.
3. Chọn Add file > Upload files.
4. Chọn tất cả 9 tệp nằm trực tiếp trong thư mục vừa giải nén.
5. Chọn Commit changes.
6. Vào Settings > Pages.
7. Chọn Deploy from a branch, branch main và folder /(root), rồi Save.
